# 2026-11-02 · InkBoy: Game Boy on e-paper with an Xbox controller

## Goal

Replicate Bo Made It's [GameBoy on E-Paper ESP32 at 30FPS](https://www.youtube.com/watch?v=XiZmM6hwwAU), which runs on exactly this board, but play with my **Xbox Series S controller** instead of the author's custom ESP32-C3 gamepad.

Code, patch and build steps: [projects/03-inkboy](../projects/03-inkboy/).

## Before starting

Backed up the Philolog firmware as **Philogotchi v1**: git tag `philogotchi-v1`, plus a full flash image in `backups/philogotchi-v1/` (git-ignored, because it holds the private nuggets).

## What I did

- **Toolchain.** InkBoy needs ESP-IDF v6.1 and has no prebuilt releases. I installed it in `~/esp/esp-idf-v6.1`, plus `cmake` and `ninja` from Homebrew, which ESP-IDF needs on macOS.
- **Xbox controller.** Upstream only connects to a BLE device named `ESP32 Gamepad`. My patch to `components/ble_gamepad/ble_gamepad.c`:
  - also connects to `Xbox Wireless Controller`
  - decodes its input report into InkBoy's raw button bits, so the default mapping works
  - keeps the link alive while the pad is idle, because the Xbox controller only reports on change and upstream drops a controller after 2 s of silence
- **No SD card yet.** InkBoy only reads games from SD. I turned the unused 4.9 MB `spiffs` partition into a FAT partition called `storage`. InkBoy falls back to it when the card doesn't mount, and `.gb` files in `internal_fs/roms/` are packed in at build time.
- **No black frame.** InkBoy already had a FILL SCREEN border mode, which scales the game 1.25× to 200×180. I made it the default.

All of this is one patch against upstream commit `823265e`: [`inkboy-xbox-internal-flash.patch`](../projects/03-inkboy/inkboy-xbox-internal-flash.patch). Games stay on my Mac and are never committed.

## Verified on the board

- InkBoy boots, the menus and fast greyscale display work, and the GAMES list comes from internal flash (`STORAGE_INTERNAL: using the storage partition`).
- The Xbox Series S controller pairs (hold the pair button until the logo flashes fast) and sends buttons: B = `20`, Menu/Start = `80`, View/Select = `10`, all as expected.
- After a reboot it **reconnects by itself**, with no pairing needed.
- Border setting reads `3` (FILL SCREEN) after the update.

## Lessons

- The panel is driven well beyond spec here. The author warns about image retention and possible damage, so I'm keeping an eye on ghosting.
- `idf.py app-flash` only rewrites the app. Settings, pairing keys and the games partition survive, which makes iterating much faster.
- The USB port stays usable for logs and flashing as long as the controller is set to **Bluetooth**.
- My scratchpad gets wiped between sessions, so a temporary Python venv went missing mid-flash. ESP-IDF's own Python env has pyserial and works for serial logging.
